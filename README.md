# 轴承故障诊断 Agent

基于 Jetson Orin Nano 的边缘 AI Agent，用 1D-CNN 自编码器做轴承异常检测，
结合 RAG + DeepSeek 生成维修工单，支持断网降级。

## 核心指标

| 指标 | 数值 |
|------|:----:|
| AUC-ROC | 1.0 |
| 正常/故障重构误差分离度 | 3 个数量级（0.00003 vs 0.19） |
| 跨负载泛化 | 1730 → 1750 RPM 测试通过 |
| 加噪鲁棒性 | 0.1 高斯噪声下正常误差 0.00662，仍低于阈值 0.01 |
| 模型大小 | 112 KB（ONNX） |
| TensorRT FP16 推理延迟 | **0.13 ms** |
| 吞吐量 | **7028 QPS** |
| 断网降级触发延迟 | < 10 ms |
